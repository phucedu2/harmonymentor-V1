# AgentsSample (tài liệu mẫu của thầy)

Ba tài liệu mẫu cho dự án giả định "BookStore Pro" (đặc tả nghiệp vụ, đặc tả chatbot AI RAG, báo cáo review code), thầy đưa để tham khảo cách viết. **Không phải đặc tả của HarmonyMentor.** Mẫu gợi ý pgvector; nhóm chọn Qdrant theo ADR-026.
Dùng trong `docs/AI_TEACHER_FEEDBACK_MAP.md` để đối chiếu từng yêu cầu của thầy với phần đã làm.

## Pedagogical wording correction

The requested “bright/dark” intuition is not used as the formal definition of Major/Minor interval quality. HarmonyMentor defines Major/Minor by interval size first. Any timbral/emotional association is described only as a listening tendency, especially for thirds.

## Scope

The 24-key overview in Lesson 1 shows the tonic triad associated with each major/minor key. Scale-degree/key theory itself remains in Lesson 2 so Lesson 1 does not reintroduce the earlier scale-degree sequencing problem.
